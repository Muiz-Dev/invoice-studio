# Template Catalog

This catalog defines the invoice template families that the product should support.

These are not just color themes.

Each template has its own:

- document mood
- layout bias
- typography direction
- density level
- business fit
- rules
- anti-rules

## Catalog Structure

Each template entry contains:

- name
- position
- intended users
- layout anatomy
- typography direction
- color strategy
- table behavior
- totals treatment
- notes and payment treatment
- PDF considerations

## Shared Template Rules

Every template must:

- preserve invoice clarity
- support long line items
- support multi-page output
- keep totals prominent
- handle missing optional fields gracefully

Every template must not:

- turn the invoice into a card dashboard
- bury the invoice number
- bury the total due
- overload the page with ornament

## 1. Minimal Ledger

### Position

The default all-purpose professional template.

### Intended Users

- consultants
- agencies
- studios
- freelancers
- small B2B businesses

### Mood

Calm, clean, precise, credible.

### Layout Anatomy

- top-left business identity
- top-right invoice title and meta
- two-column parties block
- wide line-item table
- right-aligned totals block
- quiet support information below

### Typography Direction

- modern sans for everything
- slightly stronger weight for financial emphasis
- optional mono accents for invoice number and metadata

### Color Strategy

- near-black
- warm stone neutrals
- one understated accent

### Density

Medium

### Table Behavior

- generous row spacing
- thin horizontal rules
- no cell boxing

### Totals Treatment

- compact stack
- quiet labels
- bold total due

### Notes Treatment

- plain text
- left aligned
- modest spacing

### Payment Details Treatment

- easy to scan
- visually separated by spacing or one thin rule

### Anti-Rules

- no big badges
- no filled summary card
- no decorative blocks

## 2. Editorial Serif

### Position

The premium boutique template.

### Intended Users

- luxury service providers
- design studios
- stylists
- architects
- premium consultants

### Mood

Elegant, assured, restrained.

### Layout Anatomy

- oversized invoice heading
- generous margins
- airy masthead
- quieter metadata
- softly separated parties
- open table
- totals with strong type, minimal rulework

### Typography Direction

- serif-led heading
- sans or simple serif body
- refined contrast between label and value

### Color Strategy

- charcoal or ink
- cream or ivory base
- muted metallic or earth accent

### Density

Airy

### Table Behavior

- minimal lines
- more whitespace than borders

### Totals Treatment

- typographic emphasis over background emphasis

### Notes Treatment

- editorial style text block
- softer tone

### Signature Treatment

- quiet and discreet

### Anti-Rules

- no over-ornament
- no faux luxury textures in PDF
- no heavy container borders

### Intended Users

### Mood

### Layout Anatomy

- structured but not boxed metadata

### Typography Direction

### Color Strategy

## What Makes A Template Real

A template is real only if it changes at least three of the following:

- header composition
- typography direction
- table rhythm
- totals treatment
- spacing density
- visual tone

If only color changes, it is a skin, not a template.

## First Release Recommendation

The product should ship with these first:

1. Minimal Ledger
2. Editorial Serif
3. Studio Modern
4. Warm Service
5. Contractor Utility
6. Statement Balance

These six cover most small-business and freelance use cases while demonstrating that the app supports true template diversity.

## Template Preview Requirements

The template gallery should preview:

- header attitude
- spacing density
- table rhythm
- totals style
- overall tone

The preview card should not be:

- a color swatch
- a single bar
- a generic rectangle

It should show a miniature invoice composition so the user understands the difference at a glance.

- `industries`
- `density`
- `fontDirection`
- `accentPalette`

## Long-Term Expansion

Future template packs can include:

- Event billing pack
- Legal and advisory pack
- Trade and contractor pack
- Luxury services pack
- Commerce/export pack
- Healthcare service pack

The system should be designed now so these later packs do not require rewriting the app architecture.
